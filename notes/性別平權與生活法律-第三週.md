## 一、親屬編緒論

### 📘 重點內容：狹義身分行為之特殊性

1. **要式性**
   - 須具備一定的法定方式，例：結婚、兩願離婚
   - 例外：認領行為
2. **不得代理**
   - 例外：未滿 7 歲之人被收養
3. **不得附條件或附期限**

### 📘 重點內容：親屬之種類

- **血親**
  - 自然血親
  - 法定血親（擬制血親），例：養子女與養父母
- **姻親**
  - 血親之配偶
  - 配偶之血親
  - 配偶之血親之配偶

### ✏️ 練習題

**Q2.** 小發與小星為夫妻，小星有一表妹小皮，請問小發與小皮間是否為姻親關係？

<details>
<summary>解答</summary>

**YES**

🖼️ 圖示（投影片上的親屬圖）：

```
 爺爺 ── 奶奶        外公 ── 外婆
      │                   │
      │            ┌──────┴──────┐
      父 ───────── 母          阿姨 ── 姨丈
           │                         │
小發 ──── 小星                       小皮
（夫妻）                          （小星的表妹）
```

小皮是小星（配偶）的血親 → 屬於「配偶之血親」，所以是姻親。

</details>

**Q3.** 承上題，小星與小皮間的親系、親等？

<details>
<summary>解答</summary>

📝 補充（投影片只出題，未列答案）：**旁系血親，四親等**。

計算方式（依上圖）：小星 →（1）母 →（2）外公外婆 → 往下（3）阿姨 →（4）小皮。

</details>

**Q4.** 小發與小星為夫妻，請問小發的媽媽與小星的爸爸間是否為姻親關係？

<details>
<summary>解答</summary>

**NO**

🖼️ 圖示（投影片上的親屬圖，★ 為題目問的兩人）：

```
發爸 ── ★發媽       ★星爸 ── 星媽
      │                    │
     小發 ──────────────── 小星
             （夫妻）
```

投影片結論：**血親之配偶之血親，非姻親**。

小星的爸爸對小發而言是「配偶之血親」；但小發的媽媽與小星的爸爸之間是「血親之配偶之血親」，**不在姻親的三種類型內，非姻親**。

</details>

### 📘 重點內容：親屬關係之發生

- **血親**
  - 出生（民法 §1063Ⅰ、§1065Ⅱ）
  - 認領（民法 §1065Ⅰ）
  - 收養
- **姻親**
  - 結婚

### 📘 重點內容：「推定」vs「視為」（投影片附條文）

> **民法第 1063 條**
> 1. 妻之受胎，係在婚姻關係存續中者，**推定**其所生子女為婚生子女。 ← 🟧 **可以舉證推翻**
> 2. 前項推定，夫妻之一方或子女能證明子女非為婚生子女者，得提起否認之訴。
> 3. 前項否認之訴，夫妻之一方自知悉該子女非為婚生子女，或子女自知悉其非為婚生子女之時起二年內為之。但子女於未成年時知悉者，仍得於成年後二年內為之。

> **民法第 1065 條**
> 1. 非婚生子女經生父認領者，**視為**婚生子女。其經生父撫育者，**視為**認領。 ← 🟩 **不可舉證推翻**
> 2. 非婚生子女與其生母之關係，**視為**婚生子女，無須認領。 ← 🟩 **不可舉證推翻**

👉 記法：「推定」可以用證據推翻；「視為」法律直接認定，不能用證據推翻。

### 📘 重點內容：親屬關係之消滅

- **血親**
  - 死亡（包含死亡宣告）
  - 收養關係終止與撤銷
- **姻親**
  - 死亡
  - 離婚（民法 §971）
  - 撤銷婚姻（民法 §971）

> **民法第 971 條**
> 姻親關係，因離婚而消滅；結婚經撤銷者亦同。

## 二、父母子女概論

### 📘 重點內容：婚生子女

- **意義**：由婚姻關係受胎而生之子女。（民法 §1061）
- **婚生推定**：妻之受胎係在婚姻關係存續中者，推定其所生子女為婚生子女。（民法 §1063Ⅰ）
- **Q：如果妻於婚姻關係存續中，由夫以外之他人受胎而生之子女？**
  → **否認子女之訴**（民法 §1063Ⅱ、家事事件法 §64Ⅰ）

> **民法第 1063 條**
> 1. 妻之受胎，係在婚姻關係存續中者，推定其所生子女為婚生子女。
> 2. 前項推定，**夫妻之一方或子女**能證明子女非為婚生子女者，得提起否認之訴。
> 3. 前項否認之訴，夫妻之一方自知悉該子女非為婚生子女，或子女自知悉其非為婚生子女之時起**二年**內為之。但子女於未成年時知悉者，仍得於成年後二年內為之。

> **家事事件法第 64 條**
> 1. 否認子女之訴，夫妻之一方或子女於法定期間內或期間開始前死亡者，**繼承權被侵害之人**得提起之。
> 2. 依前項規定起訴者，應自被繼承人死亡時起，於一年內為之。
> 3. 夫妻之一方或子女於其提起否認子女之訴後死亡者，繼承權被侵害之人得於知悉原告死亡時起十日內聲明承受訴訟。但於原告死亡後已逾二年者，不得為之。

👉 投影片框起來的重點：能提否認之訴的是「**夫妻之一方或子女**」（及其死亡時「**繼承權被侵害之人**」），期間「**二年**」。

### 📘 重點內容：非婚生子女

1. **認領**
   - **任意認領**：非婚生子女經生父認領者，視為婚生子女。其經生父撫育者，視為認領。（民法 §1065Ⅰ）
   - **強制認領**：有事實足認其為非婚生子女之生父者，非婚生子女或其生母或其他法定代理人，得向生父提起認領之訴。（民法 §1067Ⅰ）
     前項認領之訴，於生父死亡後，得向生父之繼承人為之。生父無繼承人者，得向社會福利主管機關為之。（民法 §1067Ⅱ）
2. **準正**
   - 非婚生子女，其生父與生母結婚者，視為婚生子女。（民法 §1064）

### 📘 重點內容：收養

- **何謂收養？** 收養他人之子女為子女時，其收養者為養父或養母，被收養者為養子或養女。（民法 §1072）

**Q5.（舉牌搶答，答對加 2,000 分）**
甲男乙女未婚生下一子丙，丙因甲之撫育而被視為甲之婚生子女。此種情形，民法上稱為？

- A）領養
- B）收養
- C）認領

<details>
<summary>解答</summary>

**C）認領**

非婚生子女經生父撫育者，視為認領（民法 §1065Ⅰ 後段）。

</details>

**Q6.（舉牌搶答，答對加 2,000 分）**
甲男乙女未婚生下一子丙，丙與乙的法律關係為何？

- A）推定為婚生子女
- B）視為婚生子女
- C）經認領後視為婚生子女

<details>
<summary>解答</summary>

**B）視為婚生子女**

投影片附條文 **民法第 1065 條**：
1. 非婚生子女經**生父**認領者，視為婚生子女。其經生父撫育者，視為認領。
2. 非婚生子女與其**生母**之關係，視為婚生子女，**無須認領**。

👉 生父要「認領」（或撫育）才視為婚生；生母則直接視為婚生，不必認領。

</details>

**Q7.**
甲男乙女婚姻關係存續中，乙女與丙男發生性行為而產下 A 子。請問丙男可以提起否認子女之訴嗎？

<details>
<summary>解答</summary>

**NO**（法律**不許親生父**提起）

> **司法院大法官釋字第 587 號（節錄）**
> 法律不許親生父對受推定為他人之婚生子女提起否認之訴，係為避免因訴訟而破壞他人婚姻之安定、家庭之和諧及影響子女受教養之權益，與憲法尚無牴觸。至於將來立法是否有限度放寬此類訴訟，則屬立法形成之自由。

</details>

## 三、遺產繼承人

### 📘 重點內容：繼承人之資格

1. **同時存在原則**（民法 §11）
2. **權利能力** → 胎兒？（民法 §7 + §1166）
3. **位居繼承順位**（配偶為當然繼承人）
4. **非喪失繼承權**

> **民法第 11 條**
> 二人以上同時遇難，不能證明其死亡之先後時，推定其為同時死亡。

> **民法第 6 條**
> 人之權利能力，始於出生，終於死亡。

> **民法第 7 條**
> 胎兒以將來非死產者為限，關於其個人利益之保護，視為既已出生。

> **民法第 1166 條**
> 1. 胎兒為繼承人時，非保留其應繼分，他繼承人不得分割遺產。
> 2. 胎兒關於遺產之分割，以其母為代理人。

### ✏️ 練習題：排排看（不能用手機找答案）

**Q8.** 請將下列之人，依照繼承順序，由先順位到後順位排列：

祖父母、父母、兄弟姊妹、直系血親卑親屬

<details>
<summary>解答</summary>

**直系血親卑親屬 → 父母 → 兄弟姊妹 → 祖父母**（民法 §1138，見下方重點內容）

</details>

### 📘 重點內容：繼承人之順序

- **血親繼承人**（民法 §1138）
  1. 直系血親卑親屬 → 以親等近者為先
  2. 父母
  3. 兄弟姊妹 → 包括全血緣、半血緣、擬制血親
  4. 祖父母
- **配偶**
  - 配偶相互之間有繼承權。（民法 §1144）

### ✏️ 練習題

**Q9.**
甲、乙結婚 30 年，有子女丙、丁，嗣後甲、乙離婚。甲與戊再婚。2 年後，甲因意外死亡，留有遺產 2 千萬元。請問甲的遺產應如何繼承？

- A）戊單獨繼承
- B）丙、丁共同繼承
- C）戊、丙、丁共同繼承
- D）乙、戊、丙、丁共同繼承

<details>
<summary>解答</summary>

**C）戊、丙、丁共同繼承**

🖼️ 圖示（✗ 為死亡者）：

```
乙 ┄┄離婚┄┄ 甲✗ ──再婚── 戊
      │
  ┌───┴───┐
  丙      丁
```

繼承人：戊、丙、丁。

📝 解析：乙已離婚，不再是配偶，無繼承權；戊為現任配偶（當然繼承人），丙、丁為第一順位直系血親卑親屬。

</details>

**Q10.**
甲男乙女結婚，生有 A 男，收養 B 女。甲與 A 出國旅遊，兩人不幸遭遇空難身亡。請問 A 的遺產應由何人繼承？

<details>
<summary>解答</summary>

**乙**

🖼️ 圖示（✗ 為死亡者）：

```
甲✗ ──結婚── 乙
       │
  ┌────┴────┐
  A✗       B（收養）
```

- 甲、A 同時遇難，推定為同時死亡（民法 §11）。
- 甲、A 同時死亡，故互不為繼承（同時存在原則）。
- 📝 解析：A 無第一順位繼承人，由第二順位「父母」繼承；甲不能繼承，只剩乙。B 女屬第三順位（兄弟姊妹），被乙排除。

</details>

**Q11.**
甲中年喪妻，有子女丙、丁。丙未婚、無子女。後來甲與乙結婚，生下一子戊。丙因意外死亡，甲依法拋棄繼承。請問丙的遺產應如何繼承？

- A）乙單獨繼承
- B）丁單獨繼承
- C）乙、丁共同繼承
- D）丁、戊共同繼承

<details>
<summary>解答</summary>

**D）丁、戊共同繼承**

🖼️ 圖示（✗ 為死亡者）：

```
妻✗ ── 甲（拋棄繼承）──再婚── 乙
    │                    │
 ┌──┴──┐                 │
 丙✗   丁                戊
```

繼承人：丁、戊。

- 兄弟姊妹包括半血緣（同父異母）。
- 📝 解析：丙無配偶、子女；第二順位父母中，生母已死亡、甲拋棄繼承 → 由第三順位兄弟姊妹丁、戊繼承。乙是丙的繼母，只是姻親，沒有繼承權。

</details>

**Q12.（動手畫畫看）**
甲男乙女為夫妻，有一子戊。甲離家與有夫之婦丙外遇，生下一女己，並撫育之。乙也與有婦之夫丁外遇，生下一子庚，由丁撫育之。嗣後，甲因意外死亡。請問甲的遺產應由何人繼承？

- A）乙、戊、己、庚
- B）乙、戊、己
- C）乙、戊、庚
- D）乙、己

<details>
<summary>解答</summary>

**C）乙、戊、庚**

🖼️ 圖示（✗ 為死亡者；┄┄ 為外遇關係）：

```
丙夫 ─結婚─ 丙 ┄┄┄┄ 甲✗ ─結婚─ 乙 ┄┄┄┄ 丁 ─結婚─ 丁妻
              │          │           │
              己         戊          庚
     （受婚生推定為                （受婚生推定為
       丙之夫的子女）                甲的子女）
```

📝 解析：

- 乙：配偶，當然繼承人。
- 戊：甲乙的婚生子女。
- 庚：乙在與甲婚姻關係存續中受胎所生 → **推定為甲的婚生子女**（民法 §1063Ⅰ），未經否認之訴推翻前，仍是甲的子女。
- 己：丙為有夫之婦，己被推定為丙之夫的婚生子女，甲的撫育不構成對「非婚生子女」的認領 → 不是甲的繼承人。

</details>

## 四、法定應繼分

> **民法第 1144 條**
> 配偶有相互繼承遺產之權，其應繼分，依左列各款定之：
> 一、與第一千一百三十八條所定第一順序之繼承人同為繼承時，其應繼分與他繼承人平均。
> 二、與第一千一百三十八條所定第二順序或第三順序之繼承人同為繼承時，其應繼分為遺產二分之一。
> 三、與第一千一百三十八條所定第四順序之繼承人同為繼承時，其應繼分為遺產三分之二。
> 四、無第一千一百三十八條所定第一順序至第四順序之繼承人時，其應繼分為遺產全部。

### 📘 重點內容：配偶之應繼分（民法 §1144）

| 配偶與誰共同繼承 | 配偶的應繼分 |
| --- | --- |
| 第一順位（直系血親卑親屬） | 平均 |
| 第二順位（父母）或第三順位（兄弟姊妹） | 1/2 |
| 第四順位（祖父母） | 2/3 |
| 無血親繼承人 | 全部 |

### 📘 重點內容：血親繼承人之應繼分（民法 §1141）

同一順序之繼承人有數人時，按人數平均繼承。

## 📋 速記總整理

| 主題 | 一句話記住 |
| --- | --- |
| 姻親三型 | 血親之配偶、配偶之血親、配偶之血親之配偶 |
| 非姻親 | 血親之配偶之血親（如兩邊親家） |
| 推定 vs 視為 | 推定可舉證推翻；視為不可 |
| 生父與非婚生子女 | 認領／撫育 → 視為婚生；生父母結婚 → 準正 |
| 生母與非婚生子女 | 視為婚生，無須認領 |
| 繼承順序 | 卑親屬 → 父母 → 兄弟姊妹 → 祖父母；配偶永遠在 |
| 同時死亡 | 互不繼承 |
| 配偶應繼分 | 平均 → 1/2 → 1/2 → 2/3 → 全部 |
